# microempresa_proyectoescolar

CHILI CLOVER - PROYECTO WEB SEGUNDA PARTE
================================================

ARCHIVOS
- index.html: estructura y contenido de la página.
- estilos.css: colores, diseño y adaptación a diferentes pantallas.

CÓMO ABRIR LA PÁGINA
1. Descargar los archivos y extraer la carpeta ZIP.
2. Abre la carpeta.
3. Haz doble clic en index.html para abrirlo en un navegador.
4. Para editar el código, puedes usar Visual Studio Code o un editor de texto.


ELEMENTOS QUE SE INCLUYEN
- Anclas: los enlaces del menú de navegación llevan a secciones de la misma página.
- Hipervínculos: los botones de WhatsApp y el enlace externo de Instagram abren otro sitio.
- Tabla: organiza productos, descripción y precio en filas y columnas.
- Formulario: permite escribir nombre, correo y mensaje. En esta versión es demostrativo y no envía ni almacena los datos.
- Iframe: incrusta un mapa de Google dentro de la página.
- Multimedia: las ilustraciones/emoji son provisionales; se deben incorporar fotografías reales de galería.
- Diseño responsivo: las reglas @media de estilos.css ajustan columnas, navegación y tamaños para pantallas pequeñas.

NOTA SOBRE EL NIVEL DEL PROYECTO
La página usa HTML y CSS básicos, por eso, el formulario no envía mensajes por sí solo. El botón de WhatsApp funcionará por completo cuando 
se sustituye el número de ejemplo por el número correcto con autorización del negocio.
